# 📊 Meta Ad Performance Analysis

## 📌 Overview

**Meta Ad Performance Analysis** is a Power BI project focused on analyzing paid advertising campaigns across **Facebook and Instagram**.

The dashboard provides insights into **reach, engagement, conversions, audience demographics, campaign budgets, and performance trends** using interactive visualizations and dynamic KPIs.

---

## 🎯 Business Objectives

* Compare Facebook vs Instagram performance
* Analyze campaign reach, engagement, and conversions
* Track advertising KPIs and budget allocation
* Understand audience behavior by gender, age, and country
* Analyze performance by ad type
* Identify weekly, monthly, and hourly trends

---

## 🗂️ Dataset

The dataset contains four tables:

| Table       | Description                                                                   |
| ----------- | ----------------------------------------------------------------------------- |
| `ad_events` | Event-level data such as impressions, clicks, shares, comments, and purchases |
| `ads`       | Ad platform, ad type, and targeting information                               |
| `campaigns` | Campaign details, dates, duration, and budget                                 |
| `users`     | User demographics, location, and interests                                    |

### Data Model

The project follows a **Star Schema**:

**Fact Table:** `ad_events`
**Dimension Tables:** `ads`, `campaigns`, `users`

---

## 📈 Key KPIs

* Impressions
* Clicks
* Shares
* Comments
* Purchases
* Engagements
* CTR
* Engagement Rate
* Conversion Rate
* Purchase Rate
* Total Budget
* Average Budget per Campaign

## 📊 Dashboard Visualizations

* **Target Gender** — Donut Chart
* **Target Age Group** — Bar Chart
* **Country** — Map
* **Calendar Month** — Heat Map
* **Weekly Trend by Ad Type** — Stacked Column Chart
* **Hourly Trend** — Area Chart
* **Ad Type & Platform** — Matrix

The dashboard includes **dynamic metric selection**, allowing users to switch between metrics such as Impressions, Clicks, Shares, Comments, Purchases, and Engagements.

---

## 🔍 Business Questions

The dashboard helps answer:

* Which platform performs better across selected metrics?
* Which ad types generate higher engagement?
* Which age and gender segments are more responsive?
* Which countries generate higher activity?
* When are users most active?
* How does performance change over time?
* How effectively are impressions converted into clicks and purchases?
* How are campaign budgets distributed?
